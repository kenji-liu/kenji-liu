## 1. GNSS 是什麼？

**GNSS（Global Navigation Satellite System，全球導航衛星系統）** 是所有以衛星提供全球定位、導航與授時（PNT：Positioning, Navigation and Timing）服務系統的總稱。

- **GPS 只是 GNSS 的其中一員**（美國），並非 GNSS 的同義詞。
- 現代接收機可同時追蹤多個星系，因此「GNSS 接收機」比「GPS 接收機」更貼切。
- 測量人員用它來：取得**位置**、建立**控制點**、進行**放樣（setting out）**、製作**地形圖與地籍圖**。

## 2. GNSS 如何運作

### 2.1 基本原理：三邊（球面）交會

衛星持續播送「我在哪裡、我的時鐘幾點」的訊號。接收機量測訊號傳播時間，乘以光速得到**到衛星的距離**：

```
距離 = 光速 × (接收時間 − 發射時間)
```

- 已知三顆衛星的位置與距離，可決定接收機的 3 維座標 (X, Y, Z)。
- 但接收機的石英鐘不如衛星原子鐘精準，**接收機時鐘誤差**是第 4 個未知數。
- 因此**至少需要 4 顆衛星**才能解出 X、Y、Z 與時間；實務上衛星越多、分布越好，結果越可靠。

### 2.2 兩種觀測量

| 觀測量 | 說明 | 精度量級 | 用途 |
|---|---|---|---|
| **偽距（Pseudorange / 碼觀測）** | 利用測距碼量測傳播時間 | 公尺～公寸 | 導航、單點定位、DGNSS |
| **載波相位（Carrier phase）** | 量測載波波長的整數個數與小數相位 | 毫米～公分 | RTK、PPK、靜態測量 |

載波相位精度高，但必須解算**整數週波未定值（Integer Ambiguity）**。解算成功稱為**固定解（Fixed）**，未成功則為**浮動解（Float）**。測量作業應以**固定解**為準。

### 2.3 為什麼衛星分布很重要？

**DOP（Dilution of Precision，精度稀釋）** 反映衛星幾何分布對精度的放大效應，值越小越好。

| DOP 類型 | 意義 |
|---|---|
| GDOP | 幾何（3D + 時間） |
| PDOP | 位置（3D） |
| HDOP | 水平 |
| VDOP | 垂直（通常比 HDOP 大） |

經驗法則：PDOP < 3 為佳；PDOP > 6 應暫停或延長觀測。

## 3. 四大全球系統與區域系統

### 3.1 全球系統

| 系統 | 營運方 | 軌道高度（約） | 備註 |
|---|---|---|---|
| **GPS** | 美國 | 20,200 km | 最早、最普及；6 個軌道面、傾角 55° |
| **GLONASS** | 俄羅斯 | 19,100 km | 傾角約 65°，高緯度表現佳；採 FDMA（各衛星頻率略有不同） |
| **Galileo** | 歐盟 | 23,222 km | 民用導向、訊號設計先進、精度佳 |
| **BeiDou（北斗）** | 中國 | MEO 約 21,500 km，另有 IGSO、GEO | BDS-3 於 2020 年完成全球組網；亞太地區可見衛星特別多 |

### 3.2 區域系統

- **QZSS（日本）**：準天頂衛星，強化亞太與日本地區。
- **NavIC / IRNSS（印度）**：區域導航系統。

### 3.3 增強系統（SBAS）

透過地球同步衛星播發修正資訊：**WAAS**（美）、**EGNOS**（歐）、**MSAS**（日）、**GAGAN**（印）、**BDSBAS**（中）。

### 3.4 常用頻率

| 星系 | 常見頻段（MHz） |
|---|---|
| GPS | L1 1575.42、L2 1227.60、L5 1176.45 |
| Galileo | E1 1575.42、E5a 1176.45、E5b 1207.14、E6 1278.75 |
| BeiDou | B1I 1561.098、B1C 1575.42、B2a 1176.45、B2b 1207.14、B3I 1268.52 |
| GLONASS | G1 約 1602、G2 約 1246（依頻道號略有差異） |

> **多頻（雙頻／三頻）** 接收機可利用不同頻率的電離層延遲差異加以消除，是公分級定位的關鍵。
> **多星系** 則提升可見衛星數與幾何強度，在樹冠下、山谷、都市環境特別有幫助。

## 4. GNSS 系統的三大組成

1. **空間段（Space Segment）**：在軌衛星，播送測距碼、導航電文與載波。
2. **控制段（Control Segment）**：地面監測站、主控站、上傳站，負責精密軌道與時鐘的測定、更新與上傳。
3. **使用者段（User Segment）**：各式接收機與天線（測量、導航、手機、UAV、車輛等）。

## 5. GNSS 接收機的主要組成

| 組件 | 功能 | 測量實務重點 |
|---|---|---|
| **天線（Antenna）** | 接收衛星訊號 | 測量型天線需有良好的**相位中心**穩定性與抗多路徑（如扼流圈 choke ring）；記錄**天線高**與**天線類型** |
| **射頻前端（RF Front-end）** | 放大、濾波、降頻 | 影響抗干擾能力 |
| **接收機晶片／主機（Receiver Engine）** | 追蹤、解碼、計算 | 支援星系與頻率數決定性能 |
| **處理器與韌體** | 演算法、RTK 引擎 | 定期更新韌體 |
| **通訊模組** | 4G/5G、UHF 電台、藍牙、Wi-Fi | 接收 NTRIP 或基站差分改正 |
| **記憶體與電源** | 儲存原始觀測檔（RINEX 等）、供電 | 靜態測量務必確認記憶體與電量 |
| **控制器／手簿與軟體** | 設定座標系、記錄點位、放樣 | 確認座標系統、投影、大地起伏模型 |
| **傾斜補償（IMU）** | 桿傾斜時仍可量測 | 可免整平，需先校正磁場／IMU |

**接收機等級概覽**

- **導航級**（手機、手持機）：公尺級。
- **GIS 級**：次公尺～公寸級。
- **測量級**（大地型）：公分～毫米級，雙頻以上、載波相位。

## 6. 定位方法與精度等級

> 以下為典型量級，實際精度受天空視野、觀測時間、基線長度、接收機等級與環境影響。

| 方法 | 原理 | 典型精度 | 備註 |
|---|---|---|---|
| **單點定位（SPP / Standalone）** | 僅用單一接收機的偽距 | 約 3–10 m | 導航用 |
| **SBAS** | 衛星播發修正 | 約 1–3 m | 免基站 |
| **DGNSS（差分）** | 基準站播發偽距改正 | 約 0.3–1 m | GIS 資料蒐集 |
| **RTK（即時動態）** | 基準站＋移動站，載波相位即時差分 | 水平約 1–2 cm、垂直約 2–3 cm | 最常用於地形測量、放樣 |
| **網路 RTK（Network RTK）** | 連續運作參考站網（VRS / FKP / MAC） | 約 1–3 cm | 免架基站，需網路 |
| **PPK（後處理動態）** | 事後以基站資料處理 | 公分級 | 無需即時通訊；UAV 常用 |
| **靜態／快速靜態測量** | 長時間同步觀測、基線解算與平差 | 毫米～公分級 | 控制測量、變形監測 |
| **PPP（精密單點定位）** | 使用精密軌道與時鐘產品 | 收斂後約公寸～公分 | 免基站，需收斂時間 |
| **PPP-RTK** | PPP 加區域大氣改正 | 公分級、快速收斂 | 新興服務 |

### 6.1 RTK 基本作業

- **固定解（Fixed）** 才可採信；**浮動解（Float）** 不得作為成果。
- RTK 基線建議不超過約 10–20 km（雙頻可略長），網路 RTK 則不受單一基線限制。
- **初始化時間、固定解比例、RMS、PDOP、衛星數**均應記錄。
- 重要點位應**重複觀測（間隔數分鐘以上，最好重新初始化）** 以檢核。

### 6.2 靜態測量

- 觀測時間與基線長度、衛星幾何有關，一般控制點至少數十分鐘到數小時。
- 以專業軟體做基線解算與**網形平差**，並檢核閉合差。

## 7. 誤差來源與訊號品質

### 7.1 主要誤差來源

| 誤差來源 | 說明 | 減輕方法 |
|---|---|---|
| **衛星軌道與時鐘誤差** | 廣播星曆精度有限 | 精密星曆、差分 |
| **電離層延遲** | 太陽活動、電子密度造成 | 雙頻／多頻組合、差分 |
| **對流層延遲** | 大氣溫、壓、濕影響 | 模型、差分、參數估計 |
| **多路徑（Multipath）** | 訊號經建物、水面、金屬反射 | 避開反射面、抗多路徑天線、提高截止高度角 |
| **接收機雜訊／天線相位中心偏差** | 硬體特性 | 使用校正天線模型 |
| **衛星幾何（DOP）** | 衛星分布不佳 | 選擇觀測時段，多星系 |
| **訊號遮蔽與周波脫落** | 樹冠、峽谷、高樓 | 多星系、延長觀測、改用其他方法 |
| **干擾與欺騙** | 無線電干擾、GNSS Jamming／Spoofing | 避開干擾源、監測訊號異常 |

### 7.2 「訊號品質」的判讀（原文所稱「街道信號」的重點）

> 原貼文的 "street signals" 較可能是指**環境（街道、城市峽谷）中的訊號條件**，在此一併說明。

- **城市峽谷（Urban Canyon）**：高樓造成遮蔽與強烈多路徑，RTK 固定困難。
- **樹冠遮蔽**：衰減訊號、造成周波脫落，山區與林地常見。
- **評估指標**：可見衛星數、**C/N0（載噪比，dB-Hz）**、PDOP、固定解狀態、RMS／標準差。
- **對策**：選擇天空開闊點位、避開反射面、延長觀測、改用偏移測量（結合全站儀）、或採 PPK/靜態後處理。

## 8. 座標系統與高程（台灣實務）

GNSS 直接產生的是 **WGS84（或 ITRF）** 地心座標與**橢球高**，工程與地籍通常需要**當地座標系統與正高**。

### 8.1 平面座標

- 台灣常用 **TWD97**（以 GRS80 橢球），投影多採 **TM2 度分帶**（中央經線 121°E，澎湖等離島另有 119°E）。
- 依成果要求確認所用**坐標框架版本**（如 TWD97 與其各期更新），並於專案中載明。
- 不同座標系統／框架之間需透過**轉換參數**（七參數、區域轉換等）處理，不可直接視為相同。

### 8.2 高程

- GNSS 得到的是**橢球高（h）**；台灣高程系統為 **TWVD2001** 之**正高（H）**。
- 關係式：**H ≈ h − N**，其中 N 為**大地起伏（Geoid Undulation）**，需使用官方大地起伏模型。
- 若沒有套用正確的大地起伏模型，高程可能出現**公尺級**偏差。重要工程應以水準測量或已知水準點**檢核與局部校正**。

### 8.3 台灣的 e-GNSS 即時定位服務

內政部國土測繪中心提供 **e-GNSS 即時動態定位系統**（連續運作參考站網），使用者以網路連線（NTRIP 協定）取得網路 RTK 改正，免架設自有基站。常見模式包含 VBS-RTK（虛擬基準站）。實際使用須先於官方平台申請帳號，詳細連線參數與規範請以**國土測繪中心**公告為準。

## 10. GNSS 與 UAV：RTK / PPK 與水土保持應用

UAV（無人機）攝影測量的成果品質，取決於**影像定位精度**與**控制點品質**，GNSS 在其中扮演核心角色。

### 10.1 三種常見方式

| 方式 | 作法 | 特點 |
|---|---|---|
| **傳統 GCP** | 地面布設標靶，以 GNSS RTK 或靜態量測其座標 | 可靠、可作檢核；需人員進入現場 |
| **UAV-RTK** | 飛行中即時接收改正，影像直接帶有公分級位置 | 可大幅減少 GCP 數量 |
| **UAV-PPK** | 記錄原始 GNSS 觀測，事後與基站（或 CORS）資料解算 | 不受即時通訊中斷影響，穩定 |

### 10.2 實務建議

- 即使採用 RTK/PPK，仍建議布設**少量 GCP 作為檢核點（ICP）**，量化精度（RMSE）。
- **高程**需特別留意：影像處理軟體使用橢球高或正高需一致，並套用相同的大地起伏模型。
- 兩期以上地形比較（如 **DoD：DEM of Difference** 的沖淤量化）時，**兩期必須使用相同座標系統、高程基準與一致的控制品質**，否則系統性偏移會被誤判為沖淤。
- 建議建立**固定的永久標點**（長期監測用控制點），以便每期重複使用並檢核。

### 10.3 適用情境舉例

- **崩塌地與土石流調查**：災前／災後兩期 DSM 差分，估算崩塌量與堆積量。
- **河道與固床工監測**：斷面變化、河床沖淤、構造物竣工後三維建模與圖資建置。
- **植生復育評估**：以高精度正射影像與 DSM 追蹤植生恢復。
- **集水區治理成效評估**：結合數值模式（如 CCHE2D、HEC-RAS）所需的地形與斷面資料。

## 11. GNSS 與全站儀（Total Station）如何搭配

| 項目 | GNSS（RTK） | 全站儀 |
|---|---|---|
| 是否需要通視 | **不需要** | 需要（測站與稜鏡通視） |
| 是否需要天空視野 | **需要** | 不需要 |
| 作業範圍 | 大範圍、遠距 | 局部、近距 |
| 相對精度 | 公分級 | 毫米級（短距離） |
| 適合地點 | 開闊地、河道、邊坡、道路 | 林下、建物旁、隧道、室內、精密放樣 |
| 速度 | 快（單人） | 需架站與整平 |

**最佳實務：兩者互補。** 以 GNSS 建立控制點，再以全站儀在遮蔽區域延伸加密；兩種儀器的成果可在同一座標系統下整合。

## 12. 優勢與局限性

### ✅ 優勢

- 全天候、24 小時、全球覆蓋。
- **不需測站間通視**，作業效率高。
- 可由單人操作，快速取得大範圍成果。
- 多星系多頻接收機提升可靠度與可用性。
- 可直接取得**絕對座標**，易與 GIS、UAV 成果整合。
- 連續站與網路 RTK 讓免基站作業成為可能。

### ⚠️ 局限性

- **需要開闊的天空視野**；室內、隧道、地下無法使用。
- 樹冠、高樓、峽谷會降低精度甚至無法固定解。
- 垂直精度通常**劣於**水平精度，且需正確的大地起伏模型。
- 受電離層活動、多路徑、干擾與欺騙影響。
- 網路 RTK 依賴行動網路與服務可用性。
- 座標系統、天線高、儀器設定錯誤，是**最常見且代價最高**的人為錯誤。

## 13. 野外作業檢查清單

**出發前**

- [ ] 儀器電量、手簿電量、備用電池；記憶體空間足夠
- [ ] 韌體、軟體更新；確認 NTRIP／e-GNSS 帳號可用
